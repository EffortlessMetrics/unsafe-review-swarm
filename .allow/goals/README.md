# Project Charters

This directory contains durable project-charter artifacts for the cargo-allow
spec-system graph. A charter records repository truth and links to proposals,
specs, plans, and support tiers; it is not a default task selector.

The work portfolio lives in GitHub issues and project metadata. The current
Codex operation is ephemeral controller state. Do not mirror the issue queue or
assign one repository-wide goal here. Register governed artifacts in
`.allow/artifacts/doc-artifacts.toml` so `cargo-allow check --profile
spec-system` can validate their source-tree graph links.
